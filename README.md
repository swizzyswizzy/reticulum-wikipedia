# reticulum-wikipedia

## Official documentation

This repository is a browser gateway on top of the Reticulum stack. Protocol behaviour, interfaces, addressing and NomadNet pages are defined by the upstream projects — not by this appliance.

| --- | --- | --- |

FAQ and community notes: [Reticulum wiki](https://github.com/markqvist/Reticulum/wiki).

A small appliance that puts a Reticulum / NomadNet node on a Raspberry Pi and exposes it as a web panel.

The Pi joins the mesh, announces itself, hosts a default Micron page, and serves a browser UI on **HTTP port 80** and **HTTPS port 443** (self-signed certificate). No extra desktop stack is required.

Repository: https://github.com/swizzyswizzy/reticulum-wikipedia

## What you need

- Raspberry Pi (Zero 2 W is enough)
- microSD card
- [Raspberry Pi Imager](https://www.raspberrypi.com/software/)
- This repository on your computer (for the SD helper)
- The Pi’s address on your LAN after first boot (router DHCP list, or a display if you add one later)

## Flash the card

1. In Raspberry Pi Imager, write **Raspberry Pi OS Lite (64-bit)** to the card. You may set Wi-Fi in the Imager as well; the helper can also write Wi-Fi on the next step.
2. Leave the card in the reader. Do not boot the Pi yet.
3. On your computer:

```bash
cd wizard
pip install -r requirements.txt
python3 rns-imager.py
```

On Windows you can run `rns-imager.bat` instead.

4. Select the boot partition, enter the Wi-Fi network (DHCP), pick the Wikipedia language, choose prefetch or on-Pi fetch, then click **RUN**.
5. Eject the card, insert it into the Pi, and apply power.
6. Wait about 3–5 minutes for first boot (user creation, SSH, clone of this repo, gateway service).

SSH (after first boot):

- user: `rtclm`
- password: `reticulum`
- hostname: `node-xxxxxx` (shown in the helper)

Root password is generated by the helper and shown on screen. Copy it from there.

Open the lounge:

```
http://<pi-ip>/
```

## Using the lounge

Home is Wikipedia: a centred search bar and a title index. Each letter walks a prefix trie. Read articles at `/` or `/wiki`, or over NomadNet at `/page/index.mu`.

Language and fetch mode are set in the wizard.

- **Prefetch:** the helper downloads that language’s title index into `wiki_data/` (progress bar), then copies it onto the card.
- **On-Pi:** the Pi downloads the same title index after install. Needs internet on the Pi.

Articles are read from `{lang}.wikipedia.org` when the node can reach the net, then cached under `/var/lib/rns/wiki_data/pages/` so mesh peers can read them later.

White-Hats Client can split a Micron page into panels (`#wh:panel id=... side=... size=...`). NomadNet ignores those lines. Guide: [docs/wh-panels.md](docs/wh-panels.md).

Add a service: create `services/name/main.py` with `title`, `path`, `get()`, optional `post()` and `setup()`. Set `is_home = True` to take over `/` and the NomadNet index. Optional `page.mu` is the NomadNet page; Python fills `{{placeholders}}`. Restart the process.

## After first boot

The service runs as systemd unit `reticulum-wikipedia`.

```bash
sudo systemctl status reticulum-wikipedia
sudo journalctl -u reticulum-wikipedia -f
```

If **Auto-update** was enabled in the helper, the Pi pulls this repository about once a minute and restarts the service when `master` changes. Log: `/var/lib/rns/update.log`.

Manual install or repair on an already-running Pi:

```bash
sudo bash install.sh
```

## Development

```bash
./start.sh
```

Runs `app.py` (port 80). Needs root or `CAP_NET_BIND_SERVICE`.

## Layout

| Path | Role |
| --- | --- |
| `app.py` | Host: HTTP + Reticulum |
| `services/wikipedia/` | Search + articles |
| `wiki_data/` | Prefetched title index + config |
| `web/` | CSS + HTMX |
| `wizard/rns-imager.py` | SD first-boot helper |
| `install.sh` / `start.sh` | Install / run |
| `systemd/` | Service + optional git-update timer |
